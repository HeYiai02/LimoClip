常见问题

首次运行弹出“Windows 已保护你的电脑”怎么办？

LimoClip 是个人开源项目，尚未购买昂贵的商业代码签名证书，因此 Windows SmartScreen 会对新发布的 exe 发出未知发布者提示。点击弹窗中的「更多信息」→「仍要运行」即可；所有源码与打包脚本均在 GitHub 公开可审计。

为什么录制的文件是 .mkv 而不是 .mp4？

普通 .mp4 必须在停录收尾时写入文件尾索引，一旦中途断电或崩溃，数小时的录像会全部损坏。LimoClip 原始录像统一采用抗断电的 .mkv（且直接适配用户映射的 NAS 盘符，停录无需二次拷贝），等你在剪辑台挑好片段导出成品时，会自动输出全生态通用的 .mp4。

可以把录像直接存到 NAS 里吗？

可以。只需在 Windows 资源管理器中将 NAS 共享目录映射为本地盘符（例如 Z:\Recordings），然后在「录制中心」将其设为保存目录即可。

为什么 B站独轮车过滤提示“已降级”？

B站游客态下发的弹幕发送者 UID 全部脱敏为 0，无法区分不同用户。前往右上角「账号与设置」通过内置 WebView2 登录你的 B站账号后，即可同时解锁原画画质与完整的单用户独轮车识别。
