# 回归冒烟清单（按改动面选择，不必全量重检）

本清单用于人工验收的轻量回归检查。纯逻辑/状态机行为应优先补自动化测试（`dotnet test` 五套），
只有无法在 headless 环境覆盖的 UI 合成、原生渲染与真机交互才需要按下列条目手动冒烟。

原则：**改到哪类代码，就检对应的 1~2 组；跨模块改动才额外检依赖方。**

## 播放器 / 渲染（改到 `Player/*`、`Controls/*`、`WorkspacePlayerManager`、`MainWindow` 布局可见性时）

- [ ] 普通窗口多路播放：画面/声音正常，弹幕按输入速率滚动。
- [ ] 双击窗格进入**焦点全屏**：弹幕流畅（后台窗格不应再渲染或推送弹幕）；退出后恢复。
- [ ] 自由布局下双击进入焦点全屏：同样流畅；退出后自由画布恢复。
- [ ] F11 桌面全屏：控制条 2.5 秒后自动隐藏，鼠标移动恢复。
- [ ] 多路直播（≥6 路）观察 GPU：默认保持源帧率；制造 GPU 压力后数秒内转 15fps，负载回落约 30 秒后恢复。
- [ ] 直播进度条：直播源固定最右端不抖动；向左拖动回看跟随；拖回边缘重新固定。回放源 seek 正常。

## 录制 / 合并（改到 `RecordingManager`、`RecordingTargetPoller`、`RecordingSessionWorker`、`SegmentMerger` 时）

- [ ] 开启自动录制后立即检查开播状态：已开播的直播间很快起录；未开播显示「待开播」并在后续轮询起录。
- [ ] 下播自动收尾；断流时按退避续录；手动停止后不会被自动重启，直到下一次下播再开播。
- [ ] 分段录制（断流重连产生 `.partNNN`）停止后自动合并成功、弹幕与高能位置正确。
- [ ] 合并失败的录像：录制中心历史行出现「重试合并」，点击后成功可打开；失败保留分片。

## 剪辑台（改到 `ClipStudioViewModel`、`LocalClipPlayerView`、`ClipStudioView`、导出/ASR 时）

- [ ] 打开完整回放正常；调节音量/静音对本地预览生效，且不受直播全局静音影响。
- [ ] 录制中在录制中心/剪辑台下拉进入「边录边剪」：能加载正在录的分片，选区受安全边界限制。
- [ ] 结束录制后自动切离线，恢复原选区与播放位置；关闭剪辑台无残留声音/定时器。
- [ ] 导出：有弹幕/无弹幕两种模式成功产出文件；取消导出正常。

## 布局 / 方案（改到 `MainWindowViewModel` 布局、`FreeformWorkspaceCanvas`、方案加载时）

- [ ] 平铺 ↔ 自由布局往返切换：不闪退、无残影、无重复出声。
- [ ] 切换布局方案（含窗格集合一致的自由方案）：不闪退，播放器正常重启。
- [ ] 房间列表拖到自由画布：落位预览正常、画布外松手不加入、拖拽期间列表点击不受影响。

## 包 / 平台（改到平台插件、登录、打包脚本时）

- [ ] 各平台房间状态/画质/弹幕连接正常（至少检本次改动涉及的两个平台）。
- [ ] 登录态读取、Cookie 保存正常。
- [ ] `scripts/package-release.ps1` 能跑通并产出可启动的 zip（发版时必做）。

## 快速通道（只改文档/文案/纯函数时）

- Release 重建 0 error；五套测试全绿；无需手动冒烟。
